# MonsterHunterSkillSim

Monster Hunter Wilds 用スキルシミュレーターです。

## 起動
GitHub Pages を有効化すると、ブラウザから `index.html` を直接利用できます。

## 主な機能
- スキル条件検索
- 登録鑑定護石
- 巨戟アーティア武器登録
- 生産護石
- 装飾品自動配置
- 追加可能スキル検索
- マイセット保存

## 保存データ
鑑定護石・巨戟アーティア・マイセットはブラウザのローカルストレージに保存されます。
同じGitHub Pages URLを使い続けることで、更新後も同じ保存領域を利用できます。
