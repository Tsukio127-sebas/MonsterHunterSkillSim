# MonsterHunterSkillSim

Monster Hunter Wilds 用スキルシミュレーターです。

## 公開構成

このリポジトリを **Public** にし、GitHub Pages で公開する構成を想定しています。

- サイト本体: GitHub Pages
- ログイン: 不要
- 鑑定護石: 各利用者のブラウザ内に保存
- 巨戟アーティア: 各利用者のブラウザ内に保存
- マイセット: 各利用者のブラウザ内に保存
- サーバー側ユーザーデータベース: なし

## 利用者ごとの保存

ユーザーデータはブラウザの `localStorage` に保存します。

そのため、同じサイトを利用しても:

- Aさんの登録護石はAさんのブラウザだけに表示
- Bさんの登録護石はBさんのブラウザだけに表示
- AさんとBさんの登録内容は混ざらない
- 登録内容をGitHubへ送信しない

という動作になります。

ただし、**同じPC・同じブラウザプロファイルを複数人で共有した場合は同じ保存領域になります。**

また、ブラウザデータを削除すると登録内容も削除されるため、「全データ書き出し」でのバックアップを推奨します。

## 主な機能

- スキル条件検索
- 登録鑑定護石
- 護石画像貼り付け / OCR
- 巨戟アーティア武器登録
- 最大強化の生産護石検索
- 装飾品自動配置
- 必要装飾品まとめ表示
- 追加可能スキル検索
- マイセット保存
- 全ユーザーデータのJSONバックアップ / 復元

## GitHub Pages

リポジトリをPublicにした後、

1. Settings
2. Pages
3. Build and deployment
4. Source: Deploy from a branch
5. Branch: main
6. Folder: /(root)
7. Save

で公開できます。

公開URLは通常:

`https://tsukio127-sebas.github.io/MonsterHunterSkillSim/`

になります。

## 外部通信

ゲームデータ取得のためWildsSim公開CSVへアクセスし、護石OCR用にTesseract.jsをCDNから読み込みます。

**鑑定護石・巨戟アーティア・マイセットなど、利用者が登録した個人データを外部へアップロードする処理はありません。**
